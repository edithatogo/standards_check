Five priority article acquisitions timed out; STROBE XML was acquired but its table had zero supported body rows. The first patch coverage failed at 56.98%. This is the baseline, not an extraction success claim.

The same survey now tries priorities before metadata, uses bounded compressed HTTP requests to fixed provider hosts, and stops Europe PMC after three consecutive incomplete batches, retaining failed and deferred terms separately. An explicit prior survey receipt can preserve unchanged successfully resolved metadata (labelled retained, not fresh); changed source blobs/IDs and incomplete outcomes are reattempted.

Use the official PMC ID converter (https://pmc.ncbi.nlm.nih.gov/tools/id-converter-api/) in batches when the maintainer configures a valid contact email via the repository variable SOURCE_API_EMAIL. Missing contact is an explicit status; do not invent contact data. Crossref exact DOI (https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/) and OpenAlex exact DOI/PMID singleton (https://developers.openalex.org/guides/get) provide bounded additional metadata and OA locator hints, not rights or source truth. The default budget is 12 unique singleton lookups per registry, priority editions before unresolved catalogue records; no paid OpenAlex content/search calls or arbitrary link dereferencing. The existing primary lookup remains separate. Conflicting IDs are reported and held, not majority-voted. ORCID is deferred to actual author-identity discrepancies; its token-based researcher registry is not a document acquisition source.

On priority XML transport/HTTP failure, use the official PMC OAI-PMH GetRecord full-text endpoint (https://pmc.ncbi.nlm.nih.gov/tools/oai/) when the archive permits it. Validate the exact OAI header, article, selected DOI and machine-readable licence with the existing source comparator. Keep the raw envelope fingerprint separate from the extracted JATS projection and never silently repin or substitute the four earlier primary sources. Candidate-only table inventory and source hashes do not grant item rights or external qualification.

The survey emits a deduplicated OA acquisition worklist with explicit identity holds, existing priority/retained sources and remaining acquisition candidates. It does not launch hundreds of full-text downloads while the observed transport failure is unresolved. Reproduce:

    python -m scripts.survey_equator_articles --catalogue CATALOGUE.json --previous PRIOR.json --output /tmp/survey.json
