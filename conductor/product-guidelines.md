# Product guidelines

1. **Authority is explicit.** Preserve verbatim source text, normalized interpretation and local guidance as distinct fields with separate provenance.
2. **Machine-readable first.** Canonical structured data generates Markdown, HTML, PDF, DOCX, Typst, LaTeX, API and agent views. Presentation formats never become hidden databases.
3. **Deterministic before agentic.** Rules, arithmetic, version resolution and rendering are reproducible. Models may propose inputs and candidate evidence but cannot silently change authority.
4. **Evidence-scaled claims.** Use the ladder contracted → source verified → compiler verified → fixture proven → opt-in live proven → externally validated → publicly accepted.
5. **Human-centred safety.** Consequential assessments require review, traceable evidence and an appeal or correction path.
6. **Accessible by construction.** Every visual artefact has a semantic scene graph, reading order, text equivalent and contrast/keyboard requirements.
7. **Local-first and privacy-preserving.** Network, telemetry and external writes are off by default.
8. **Open but rights-aware.** Code may be permissively licensed while each standards item carries its own rights and redistribution policy.
9. **Thin integrations.** Cross-repository adapters consume contracts; they do not copy domain logic.
10. **No completion theatre.** Planning, generated files and configured CI are not treated as proof that behaviour ran successfully.
