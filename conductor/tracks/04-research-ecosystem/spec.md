# Research ecosystem contracts

Track 04 qualifies exchanges between StandardFlow and concrete receiving systems.
The current ecosystem-evidence schema, exact producer/consumer versions and explicit
rights/applicability/held states define each contract. A schema-valid export alone
cannot establish receiving behavior. Start with synthetic or rights-cleared fixtures,
measure round-trip conservation and record consumer failure and rollback behavior.
Assess CEDAR/MIRcat reuse before adding another representation. Keep optional data
mirrors distinct from code, source authority and hidden evaluation references.

Implementation remains planned until an actual consumer and its contract are pinned.
See [plan](plan.md), [issue #161](https://github.com/edithatogo/standards_check/issues/161)
and [dataset issue #162](https://github.com/edithatogo/standards_check/issues/162).
