# Platform foundation

## Objective

Establish exact-pinned Conductor, the Rust workspace, authority boundaries, evidence semantics and a network-free CI baseline.

## Acceptance boundaries

- Status, implementation and evidence remain independently recorded.
- Network, telemetry and external writes remain disabled by default.
- Rights, security, migration and rollback consequences are explicit.
- No plan or path is represented as implemented behaviour.

## Dependencies

None.
