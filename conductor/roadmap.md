# StandardFlow roadmap

The roadmap deliberately separates standards knowledge, canonical representation, artefact engines, applicability/evidence, interfaces, federation and assurance.

## Short horizon: establish one trustworthy authority

- Complete the brownfield estate audit and truthfully classify existing content, generated outputs, licences, placeholders and tests.
- Establish the Rust workspace, exact-pinned Conductor plugin and repository-standards inheritance.
- Define Canonical Standard Pack v1, stable item identifiers, source anchors, rights policy, relationship graph and content lockfile.
- Prove end-to-end generation with a small rights-clear reference slice covering PRISMA, CONSORT, AI/prediction and economic-evaluation use cases.
- Replace Markdown-to-JSON reverse parsing with canonical data → generated views.
- Build generic checklist/form and semantic diagram/scene-graph kernels.
- Implement all four PRISMA 2020 flow templates, arithmetic checks and accessible text equivalents.
- Import `standardflow` history into a quarantine namespace; retain Apache-2.0 notices and prove parity before cutover.
- Establish immutable-pinned CI, contract drift checks, hostile-input controls and evidence receipts.

## Medium horizon: make the platform operationally useful

- Deterministic version/extension resolution and an explainable applicability DSL.
- Evidence expectations, stable document anchors, human adjudication and semantic reassessment after standards updates.
- Journal, funder, registry and institutional profiles without conflating policy with base standards.
- Standards surveillance, rights review, translation and accessibility workflows.
- CONSORT, STROBE/STARD, prediction, diagnostic and generic research-diagram packs.
- Publication document pipeline for HTML, PDF, DOCX, Typst, LaTeX and submission bundles.
- Shared Rust facade with CLI, static API, OpenAPI/HTTP and authority-annotated MCP tools.
- Signed WASI components, offline WASM/PWA workbench and generated SDKs.
- RO-Crate and W3C PROV exports; archival identifiers and deterministic research-object packaging.
- Performance budgets, scale tests and a gated Mojo accelerator experiment.

## Long horizon: federate and validate

- Signed federated pack registry, trust roots, revocation, mirrors and standards-authoring studio.
- Exact-pinned SearchRight, SourceRight and AuthenText integrations with degraded modes and canaries.
- Cross-repository release train and optional umbrella research workbench without merging domain cores.
- Privacy-preserving hosted operation, tenancy, regional policy, backup/restore and incident rehearsal.
- Independent methodological, security, accessibility and usability evaluation.
- Sustainable standards-author governance, dispute resolution, succession and transparent evidence debt.
- A 1.0 release only when canonical authority, rights, migrations, security, reproducibility, operations and external evaluation have current evidence.
