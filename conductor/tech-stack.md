# Tech Stack

- **Core Scripts:** Bash, Make.
- **Conversion Engine:** Pandoc (markdown to latex/typst/docx/pdf/html).
- **Primary Data Format:** Markdown (canonical checklists), YAML (metadata/provenance).
- **Primary Outputs:** Typst (`.typ`), LaTeX (`.tex`), HTML, PDF.
- **Node.js/Python (Optional tooling):** Validation and specific scripting (like `find_latest_checklist.py`).
