# PRISMA 2020 diagram recipes

These four recipes are data, not executable code. Each consumes `dev.standardflow.prisma-flow.v1`, declares the source pack `org.prisma/prisma/2020`, and produces a deterministic semantic scene rendered as accessible SVG, text or canonical scene JSON.

The recipe files do not carry review counts and do not become a review system of record. Counts must come from validated input, ideally a SearchRight evidence envelope or an equivalently governed source.
