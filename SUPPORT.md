# Support

Start with the [README](README.md), [Contributing](CONTRIBUTING.md),
[examples](examples/) and existing [issues](https://github.com/edithatogo/standards_check/issues).
This is an experimental standards platform with maintained canonical Rust code
and a preserved legacy document/host surface; available support depends on the
affected version and its documented maintenance status.

For ordinary usage or build questions, open an issue with the command, exact
version or commit, expected behaviour, observed behaviour and a small synthetic
reproduction. Use an existing [issue template](.github/ISSUE_TEMPLATE/) where relevant.
For an accessibility barrier, follow [Accessibility](ACCESSIBILITY.md).
For a suspected vulnerability, follow [Security](SECURITY.md) and **do not**
publish exploit details. For a conduct concern, follow the
[Code of conduct](CODE_OF_CONDUCT.md) and the private reporting route listed there.

Do not attach real clinical or personal records, credentials, private source
materials or unlicensed reporting-guideline text. This is a single-maintainer
project; no support SLA, guaranteed fix date or second reviewer is promised.
