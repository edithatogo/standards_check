# CONSORT for Cluster Crossover Trials

> Scope: The CONSORT extension for cluster randomised crossover trials (CRXO) provides reporting guidelines for trials where clusters of participants receive multiple interventions in a crossover design. This extension addresses the specific methodological considerations of CRXO trials, including carryover effects, within-cluster correlation, and period effects.
>
> Reference: McKenzie JE, Taljaard M, Hemming K, Arnup SJ, Giraudeau B, Eldridge S, Hooper R, Kahan BC, Li T, Moher D, Turner EL, Grimshaw JM, Forbes AB. Reporting of cluster randomised crossover trials: extension of the CONSORT 2010 statement with explanation and elaboration. BMJ. 2025;388:e080472.

## Instructions
- Use task list items for checklist boxes; these become interactive checkboxes in PDF.
- Use a span with class `.textfield` for free‑text fields.
- Report all applicable items from the CONSORT-CRXO extension checklist.

## Title

- [ ] **1a. Identification as a cluster randomised crossover trial:** Indicate in the title that the trial is a cluster randomised crossover trial.

- [ ] **1b. Key elements in title:** Include in the title the condition or intervention being evaluated, the comparator, the type of trial (cluster randomised crossover), and the population.

## Abstract

- [ ] **2a. Structured summary:** Present a structured summary including, as applicable: background; objectives; methods (including study setting, clusters, participants, interventions, outcomes, sample size, randomization, blinding, and statistical methods); results (including participant flow, recruitment, baseline data, numbers analyzed, outcomes, and adverse events); and conclusions.

- [ ] **2b. Trial design in abstract:** Clearly state in the abstract that the trial is a cluster randomised crossover trial.

## Introduction

- [ ] **3a. Scientific background:** Explain the scientific background and rationale for the trial, including justification for using a cluster randomised crossover design.

- [ ] **3b. Specific objectives:** Clearly state the specific objectives or hypotheses, including prespecified subgroup or interaction analyses related to the cluster crossover design.

## Methods

- [ ] **4a. Trial design description:** Describe the trial design (cluster randomised crossover) and methods used to generate the randomization sequence, including the number of periods and sequences.

- [ ] **4b. Important changes:** Describe any important changes to methods after trial commencement (such as eligibility criteria), with reasons.

- [ ] **5a. Eligibility criteria for clusters:** Specify eligibility criteria for clusters and participants, including any restrictions on cluster size or composition.

- [ ] **5b. Settings and locations:** Describe the settings and locations where the data were collected, including any variations across periods.

- [ ] **6. Interventions:** Clearly describe the interventions for each group and how they were delivered, including any adaptations for the cluster crossover design.

- [ ] **7a. Outcomes: overview:** Provide an overview of all outcomes measured in the trial, including primary, secondary, and other prespecified outcomes.

- [ ] **7b. Outcomes: definitions:** For each outcome, provide a precise definition including the measurement variable (what is being measured), method of measurement (how it is measured), metric (how it is summarized), and time point(s) of measurement.

- [ ] **7c. Outcomes: changes:** If any outcomes were modified after the trial commenced, describe the changes and explain why they were made.

- [ ] **8a. Sample size determination:** Explain how the sample size was determined, including assumptions about intracluster correlation, within-cluster autocorrelation, and period effects.

- [ ] **8b. Interim analyses:** If applicable, explain any interim analyses and stopping guidelines, including considerations specific to the cluster crossover design.

- [ ] **9a. Randomization sequence:** Describe the mechanism used to generate the randomization sequence, including any stratification or blocking by cluster characteristics.

- [ ] **9b. Allocation concealment:** Describe the mechanism used to implement the random allocation sequence (such as central telephone; web-based), describing any steps taken to conceal the sequence until interventions were assigned.

- [ ] **10. Blinding:** Describe who was blinded after assignment to interventions (for example, participants, personnel, outcome assessors) and how; explain how blinding was maintained across periods.

- [ ] **11a. Statistical methods: overview:** Describe the statistical methods used to compare groups for primary and secondary outcomes, including any methods for adjusting for confounding or clustering.

- [ ] **11b. Statistical methods: cluster crossover specific:** Specify methods for handling carryover effects, period effects, and within-cluster correlation; describe approaches for dealing with missing data and multiplicity adjustments.

## Results

- [ ] **12. Participant flow:** Describe the flow of clusters and participants, including those who were excluded from the analysis, and reasons for drop-outs and exclusions; provide flow diagrams for each period if applicable.

- [ ] **13a. Recruitment periods:** Report dates defining the periods of recruitment and follow-up for each sequence.

- [ ] **13b. Reasons for trial end:** Report reasons why the trial ended or was stopped, including any variations across sequences.

- [ ] **14. Baseline data:** Give characteristics of clusters and participants at baseline for each sequence, including factors that might affect the outcomes.

- [ ] **15. Numbers analyzed:** Report the numbers of clusters and participants in each group analyzed for each outcome, indicating whether analysis was by original assigned groups; report numbers for each period if applicable.

- [ ] **16a. Outcomes and estimation:** Report results for each outcome and each group, with confidence intervals and precise p-values; report results for each period if applicable.

- [ ] **16b. Outcomes: cluster crossover specific:** Report assessments of carryover effects, period effects, and within-cluster correlation; present results adjusted for these factors as appropriate.

- [ ] **17. Ancillary analyses:** Report results of any other analyses performed, including subgroup analyses and adjusted analyses, especially those related to the cluster crossover design.

- [ ] **18. Harms:** Report all important harms or unintended effects in each group, including any that occurred during crossover periods.

## Discussion

- [ ] **19. Limitations:** Discuss limitations of the trial, including potential sources of bias and imprecision, and limitations specific to the cluster crossover design.

- [ ] **20. Generalizability:** Comment on the generalizability (external validity) of the trial results, particularly to other settings where cluster crossover trials might be used.

- [ ] **21. Interpretation:** Discuss the results, taking into account the study's limitations and the results from other relevant studies, particularly those with cluster crossover designs.

## Other Information

- [ ] **22. Registration:** Provide the trial registration number and name of the registry; indicate if the cluster crossover design was specified in the registry.

- [ ] **23. Protocol:** Indicate where the full trial protocol can be accessed, including any amendments related to the cluster crossover design.

- [ ] **24. Funding:** Describe sources of funding and other support (such as supply of drugs), and the role of funders.
