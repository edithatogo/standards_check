# PRISMA-S Checklist

> Scope: The PRISMA-S (Search) extension provides guidance for reporting literature searches in systematic reviews, covering multiple aspects of the search process.
>
> Reference: Rethlefsen ML, Kirtley S, Waffenschmidt S, Ayala AP, Moher D, Page MJ, Koffel JB; PRISMA-S Group. PRISMA-S: an extension to the PRISMA Statement for Reporting Literature Searches in Systematic Reviews. Syst Rev. 2021;10(1):39.

## Instructions
- Use task list items for checklist boxes; these become interactive checkboxes in PDF.
- Use a span with class `.textfield` for free‑text fields.
- Report all applicable items from the PRISMA-S checklist.

## Rationale and Objectives

- [ ] **S1. Rationale:** Describe the rationale for the search, including how it relates to the review question and objectives.

## Search Methods

- [ ] **S2. Information sources:** List all information sources searched or browsed (e.g., databases, registers, websites, organizations), including database thesauri and controlled vocabulary used for searching.

- [ ] **S3. Search strategy rationale:** Describe the rationale for the search strategy, including how it was designed to retrieve all relevant material, and any limitations of the search approach.

- [ ] **S4. Full search strategies:** Provide the complete search strategies for at least one database, including controlled vocabulary (e.g., subject headings, thesaurus terms) and free-text terms, Boolean operators, and any limits or filters used.

- [ ] **S5. Search strategy modifications:** Describe any modifications to search strategies during the search process (e.g., addition of new terms, removal of terms, changes to limits or filters) and the rationale for these changes.

- [ ] **S6. Limits and filters:** Describe all limits and filters used in the search strategies (e.g., publication date, language, document type) and the rationale for their use.

- [ ] **S7. Database platform:** For each database, specify the database platform used (e.g., Ovid, EBSCOhost) and the date the search was conducted.

- [ ] **S8. Supplementary searches:** Describe any supplementary search methods used (e.g., citation searching, handsearching of journals, searching of trial registers, websites, or conference proceedings) and provide details of these searches.

## Search Management

- [ ] **S9. Search documentation:** Describe how the searches were documented (e.g., search logs, audit trail) and whether version control was used.

- [ ] **S10. Peer review of search strategies:** State whether the search strategies were peer reviewed and, if so, describe the peer review process (e.g., who conducted the peer review, checklist used, results of peer review).

- [ ] **S11. Selection of information sources:** Describe the rationale for selecting the information sources searched, including any that were considered but not searched and the reasons for their exclusion.

## Search Results

- [ ] **S12. Number of records identified:** Report the number of records identified from each information source, including the number of duplicates removed.

- [ ] **S13. Updates:** Describe any updates to the searches, including the date of the update search and any changes to the search strategy.
