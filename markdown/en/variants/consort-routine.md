# CONSORT for Randomised Controlled Trials Using Cohorts and Routinely Collected Data

> Scope: The CONSORT extension for Randomised Controlled Trials Using Cohorts and Routinely Collected Data (CONSORT-ROUTINE) provides reporting guidelines for trials conducted using existing cohorts and routinely collected health data. This extension addresses specific methodological considerations of trials using routinely collected data, including data quality, completeness, and generalizability.
>
> Reference: Kwakkenbos L, Imran M, McCall SJ, McCord KA, Fröbert O, Hemkens LG, Zwarenstein M, Relton C, Rice DB, Langan SM, Benchimol EI, Thabane L, Campbell MK, Sampson M, Erlinge D, Verkooijen HM, Moher D, Boutron I, Ravaud P, Nicholl J, Uher R, Sauvé M, Fletcher J, Torgerson D, Gale C, Juszczak E, Thombs BD. CONSORT extension for randomised controlled trials using cohorts and routinely collected data: checklist and explanation and elaboration. BMJ. 2025;388:e081124.

## Instructions
- Use task list items for checklist boxes; these become interactive checkboxes in PDF.
- Use a span with class `.textfield` for free‑text fields.
- Report all applicable items from the CONSORT-ROUTINE extension checklist.

## Title

- [ ] **1. Identification as a ROUTINE trial:** Indicate in the title that the trial uses cohorts and routinely collected data and specify the data source(s).

## Abstract

- [ ] **2a. Structured summary:** Present a structured summary including, as applicable: background; objectives; methods (including study setting, participants, interventions, outcomes, sample size, randomization, blinding, and statistical methods); results (including participant flow, recruitment, baseline data, numbers analyzed, outcomes, and adverse events); and conclusions.

- [ ] **2b. Data sources in abstract:** Clearly state in the abstract the cohort(s) and routinely collected data source(s) used in the trial.

## Introduction

- [ ] **3a. Scientific background:** Explain the scientific background and rationale for the trial, including justification for using cohorts and routinely collected data.

- [ ] **3b. Specific objectives:** Clearly state the specific objectives or hypotheses, including any prespecified subgroup analyses related to the ROUTINE design.

## Methods

- [ ] **4a. Trial design description:** Describe the trial design and methods used to generate the randomization sequence, including details of the cohort and routinely collected data sources.

- [ ] **4b. Important changes:** Describe any important changes to methods after trial commencement (such as eligibility criteria), with reasons.

- [ ] **5a. Eligibility criteria:** Specify eligibility criteria for participants, including any restrictions related to availability in the cohort or routinely collected data sources.

- [ ] **5b. Settings and locations:** Describe the settings and locations where the cohort and routinely collected data were collected.

- [ ] **6. Interventions:** Clearly describe the interventions for each group and how they were delivered, including any adaptations for the ROUTINE design.

- [ ] **7a. Outcomes: overview:** Provide an overview of all outcomes measured in the trial, including primary, secondary, and other prespecified outcomes.

- [ ] **7b. Outcomes: definitions:** For each outcome, provide a precise definition including the measurement variable (what is being measured), method of measurement (how it is measured), metric (how it is summarized), and time point(s) of measurement.

- [ ] **7c. Outcomes: data sources:** For each outcome, specify which data source(s) were used to measure it and justify the choice of data source(s).

- [ ] **7d. Outcomes: changes:** If any outcomes were modified after the trial commenced, describe the changes and explain why they were made.

- [ ] **8a. Sample size determination:** Explain how the sample size was determined, including assumptions about data quality, completeness, and availability in the routinely collected data sources.

- [ ] **8b. Interim analyses:** If applicable, explain any interim analyses and stopping guidelines, including considerations specific to the ROUTINE design.

- [ ] **9a. Randomization sequence:** Describe the mechanism used to generate the randomization sequence, including any stratification or blocking.

- [ ] **9b. Allocation concealment:** Describe the mechanism used to implement the random allocation sequence, describing any steps taken to conceal the sequence until interventions were assigned.

- [ ] **10. Blinding:** Describe who was blinded after assignment to interventions (for example, participants, personnel, outcome assessors) and how; explain any challenges specific to blinding in ROUTINE trials.

- [ ] **11a. Statistical methods: overview:** Describe the statistical methods used to compare groups for primary and secondary outcomes, including any methods for adjusting for confounding.

- [ ] **11b. Statistical methods: ROUTINE specific:** Specify methods for handling missing data, data quality issues, and any methods specific to analyzing routinely collected data; describe approaches for dealing with potential biases in routinely collected data.

## Results

- [ ] **12. Participant flow:** Describe the flow of participants, including those who were excluded from the analysis, and reasons for drop-outs and exclusions; report the number and reasons for missing data from routinely collected sources.

- [ ] **13a. Recruitment periods:** Report dates defining the periods of recruitment and follow-up.

- [ ] **13b. Reasons for trial end:** Report reasons why the trial ended or was stopped.

- [ ] **14. Baseline data:** Give characteristics of participants at baseline, including factors that might affect the outcomes; report characteristics of the cohort and routinely collected data sources.

- [ ] **15. Numbers analyzed:** Report the numbers of participants in each group analyzed for each outcome, indicating whether analysis was by original assigned groups; report the number of participants with evaluable data from routinely collected sources.

- [ ] **16a. Outcomes and estimation:** Report results for each outcome and each group, with confidence intervals and precise p-values.

- [ ] **16b. Outcomes: data quality:** Report assessments of data quality, completeness, and any validation procedures used for routinely collected data.

- [ ] **17. Ancillary analyses:** Report results of any other analyses performed, including subgroup analyses and adjusted analyses.

- [ ] **18. Harms:** Report all important harms or unintended effects in each group, including those captured by routinely collected data sources.

## Discussion

- [ ] **19. Limitations:** Discuss limitations of the trial, including potential sources of bias and imprecision, and limitations specific to using cohorts and routinely collected data.

- [ ] **20. Generalizability:** Comment on the generalizability (external validity) of the trial results, particularly to other settings where routinely collected data might be used.

- [ ] **21. Interpretation:** Discuss the results, taking into account the study's limitations and the results from other relevant studies; interpret the clinical significance of findings from ROUTINE trials.

## Other Information

- [ ] **22. Registration:** Provide the trial registration number and name of the registry; indicate if the ROUTINE design was specified in the registry.

- [ ] **23. Protocol:** Indicate where the full trial protocol can be accessed, including details of data sources and analysis plans for routinely collected data.

- [ ] **24. Funding:** Describe sources of funding and other support, and the role of funders.
